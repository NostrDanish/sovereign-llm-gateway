# Improvement Deep-Dive — sovereign-llm-gateway — 2026-10-21

## Top recommendations (ranked, with effort S/M/L)
1. **Add the missing access-control layer ('allowlist design')** — today ANY gift wrap that decrypts is exec'd into a local LLM and answered, with no sender check, no rate limit, no cost cap. Minimal viable: `ALLOWED_NPUBS` env allowlist checked on the unwrapped sender pubkey; better: plug in wot-oracle scores (sibling repo) as a thresholded trust gate. Without this the bot is a free anonymous LLM proxy. [S for static allowlist, M for WoT gate]
2. **Fix the same broken NDK pattern as fleet siblings**: `import { NDK }` (named import of a default export) + no signer configured — the gateway cannot unwrap or reply as written. Add `NDKPrivateKeySigner` from env + package.json with pinned `@nostr-dev-kit/ndk`. [S]
3. **Filter the subscription by recipient**: `ndk.subscribe({ kinds: [1059] })` downloads every gift wrap on the relay network-wide; add `'#p': [<gateway pubkey>]`. [S]
4. **De-hardcode the model**: `ollama run llama3.2` (2024-era); take `OLLAMA_MODEL` from env and document RAM expectations. [S]
